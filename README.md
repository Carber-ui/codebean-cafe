# 카페 홈페이지 시안

## 실행 방법
프로젝트 폴더에서 로컬 웹 서버를 실행한 뒤 `http://localhost:8765/index.html`처럼 접속해 주세요. 예를 들어 Python이 설치되어 있다면 프로젝트 폴더에서 `python -m http.server 8765`를 실행할 수 있습니다. 로그인 기능은 브라우저의 보안 기능을 사용하므로 `file://`로 직접 열기보다 로컬 웹 서버로 접속해야 합니다. 웹 폰트는 인터넷 연결이 없으면 기본 글꼴로 표시됩니다.

## 구성과 수정할 곳
- `index.html`: 첫 화면과 메뉴·혜택 소개를 수정합니다.
- `menu.html`: 메뉴 분류, 검색과 메뉴 목록 화면을 수정합니다.
- `about.html`: 카페 소개와 매장 안내를 수정합니다.
- `notices.html`, `notices.css`: 공지사항 페이지의 할인·적립 혜택 내용과 디자인을 수정합니다.
- `account.html`, `account.css`, `account.js`, `account-status.js`: 로그인·회원가입 화면과 로그인 상태 표시를 수정합니다.
- `order.html`, `order.css`, `order.js`: 주문 화면, 장바구니와 가상 결제 과정을 수정합니다.
- `style.css`: 색상과 화면 배치를 수정합니다.
- `app.js`: 상단 메뉴와 첫 화면 스크롤을 수정합니다.
- `catalog.js`: 음료 52종과 푸드 14종의 이름, 설명, 이미지 위치를 수정합니다. 메뉴와 주문 화면이 함께 사용합니다.
- `pricing.js`: 메인, 메뉴와 주문 화면에 공통으로 표시할 메뉴별·분류별 가격을 수정합니다.
- `menu.js`: 메뉴 화면의 검색·분류 기능을 수정합니다.
- `assets/hero.png`, `assets/menu-grid.png`, `assets/coffee-grid.png`, `assets/latte-tea-grid.png`, `assets/smoothie-grid.png`, `assets/fruit-grid.png`: 로고 없는 AI 생성 이미지입니다. 추가된 이미지도 포함해 메뉴 이미지는 각각 3열 × 2행으로 구성되어 있으며 `catalog.js`의 image와 position 값으로 표시합니다.
- `assets/cafe-interior.png`: 첫 화면에 사용하는 AI 생성 카페 공간 이미지입니다.
- `assets/event-military.png`, `assets/event-card.png`, `assets/event-points.png`: 혜택 영역에 사용하는 AI 생성 일러스트입니다.

메가MGC커피의 음료 메뉴를 참고해 구성한 과제용 예시입니다. 사진은 실제 메가커피 사진을 가져와 로고를 지운 것이 아니라 AI로 새로 생성한 연출 이미지이며 실제 음료의 모양이나 재료와 다를 수 있습니다. 메뉴 구성, 가격, 알레르기와 영양 정보, 이벤트와 사업자 정보는 실제 운영 정보가 아닙니다.

## 이미지 생성 정보
기본 이미지 생성 도구를 사용했습니다. 요청한 이미지 유형은 노란 배경 카페 대표 이미지와, 로고 없는 커피·라떼·티·에이드·스무디·디저트를 각각 3×2 칸에 담은 카탈로그용 제품 사진입니다.

카페 공간 이미지 생성 요청: 햇살이 드는 동네 카페, 원목 테이블과 크림색 벽, 테이블 위 커피와 작은 빵을 담은 자연스러운 사진. 로고와 글자는 넣지 않음.

혜택 이미지 생성 요청: 군인 캐릭터, 카드 캐릭터, 포인트 도장 캐릭터를 크림색 바탕과 차분한 올리브·노란색으로 각각 그린 귀여운 카페용 일러스트. 글자와 로고는 넣지 않음.

## 상단 메뉴
첫 화면의 상단 바는 반투명으로 표시됩니다. PC에서는 메뉴에 마우스를 올리면 하위 메뉴가 펼쳐지고, 터치 화면에서는 상단 메뉴를 눌러 열 수 있습니다. 메뉴소개 안의 음료와 푸드를 선택하면 해당 분류로 이동합니다. 카페 소식의 공지사항을 누르면 별도 공지사항 페이지로 이동합니다. 브랜드 이야기와 매장 찾기는 준비 중 항목입니다.

## 메뉴 검색
검색창에서 메뉴 이름이나 초성(예: `ㄸㄱ`)으로 검색할 수 있습니다. 온도 선택과 메뉴 분류는 검색 결과에도 함께 적용됩니다. 전체 목록은 처음 18개를 보여 주고, 나머지는 메뉴 더 보기로 확인할 수 있습니다.

## 이벤트 및 첫 화면
공지사항 페이지에서 군인 할인, 나라사랑카드와 다회 구매 적립, 개인컵 할인, 생일 할인, 첫 가입 적립, 음료·푸드 동시 구매 할인, 스탬프 적립을 확인할 수 있습니다. 안내 화면이며 실제 결제·할인·포인트·스탬프·쿠폰 시스템은 연결되어 있지 않습니다. 첫 화면 이미지와 문구의 등장 효과는 `style.css`의 `hero-copy-in`과 `hero-image-in`에서 수정합니다.

첫 화면의 주요 영역은 화면 높이에 맞춰 표시됩니다. 마우스 휠이나 터치로 스크롤하면 화면 크기의 영역 사이를 천천히 이동합니다. 메뉴 페이지는 목록을 자유롭게 스크롤할 수 있습니다. 움직임 줄이기를 설정한 기기에서는 화면 자동 전환과 등장 효과가 꺼집니다.

## 로그인과 회원가입
계정과 로그인 상태는 현재 브라우저의 로컬 저장소에만 저장됩니다. 다른 브라우저나 기기와 공유되지 않으며, 브라우저 데이터를 지우면 사라질 수 있습니다. 비밀번호는 원문이 아닌 해시로 저장하지만, 서버가 없는 시연용 기능이므로 실제 서비스에는 별도의 서버 인증과 보안 설계가 필요합니다.

## 주문 시연
로그인 후 주문 화면에서 전체 메뉴를 아래로 둘러보고 장바구니에 담을 수 있습니다. 주문 메뉴를 선택하면 가능한 HOT·ICE 변경, 얼음 양과 추가 옵션을 고를 수 있습니다. 에이드는 당도와 알로에·코코넛 젤리 추가를 선택할 수 있습니다. 대부분의 음료는 사이즈 업을 선택할 수 있으며 1,000원이 추가됩니다. ICE 변경은 500원, 샷과 바닐라 시럽은 각각 500원, 펄은 700원이 추가됩니다. 결제 전 매장, 포장·매장·배달 이용, 일회용품 수령과 요청사항, 결제 수단을 선택할 수 있습니다. 배달을 선택하면 주소를 입력하며, 입력 주소는 주문 완료 화면을 닫으면 사라집니다. 표시된 매장명은 추후 수정할 수 있습니다. 결제하기를 누르면 선택한 내용을 확인할 수 있는 주문 완료 화면이 나타납니다. 휴대폰에서는 하단 장바구니 버튼으로 담은 메뉴를 확인할 수 있습니다. 토스·카카오페이·네이버페이·카카오뱅크에는 각 서비스의 앱스토어 아이콘을 사용하며 카드·계좌이체에는 일반 아이콘을 사용합니다. 장바구니는 현재 브라우저에 계정별로 저장되고 주문 완료 시 비워집니다. 실제 결제, 매장 주문 접수, 혜택 할인과 포인트 적립은 연결되어 있지 않습니다. 표시 가격은 시연용이며 `pricing.js`의 `prices`(메뉴별)와 `categoryPrices`(그 외 분류별)에서 수정할 수 있습니다.

매장 정보는 `stores-data.js`에서 수정하며, 매장 안내와 주문 화면에 함께 반영됩니다. 매장 주소와 영업시간은 과제용으로 설정한 정보입니다.
